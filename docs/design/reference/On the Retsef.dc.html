On the Retsef: screen set for build

This file holds the final screens only. There are 21 phone screens (390×844, P01–P21) and the matching 21 desktop screens (1280×800, D01–D21), with the same numbers across both sets. Tokens, component props, responsive rules and behavior notes are in HANDOFF.md. Every piece that repeats is its own component file (Dial, Logo, Btn, ClueCard, Scoreboard, TeamPanel, GameHeader, Soundboard, Starfield, GamePhone, GameDesktop).

Phone · 390×844

The main target, built for one-handed use: primary actions sit at the bottom and every tap target is at least 44px.
